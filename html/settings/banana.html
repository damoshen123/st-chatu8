基础设置

GPT Image 2 等 4K 模型规则：最长边 ≤ 3840，宽高需为 16 的倍数，总像素上限约 8.3MP（1:1 满分率为 2880x2880）。
原生生图与独立 Edits 接口说明
  • 接口彻底分离：
    • 文生图：调用 /v1/images/generations 接口，严格发送纯 JSON 参数，绝不附加非标 image 字段；
    • 图生图 / 修图：当有角色参考图、预设图或处于修图模式时，调用独立的 /v1/images/edits 接口，默认使用二进制表单（multipart/form-data）上传图片文件。
  • 特殊公益站兼容：若公益站使用单数形式（如 /v1/image/generation 与 /v1/image/edit），可在上方对应的自定义输入框中分别指定。
  • 纯文生图模型：若站点模型仅支持文生图，可将「处理策略」切换为「纯文生图模式」。
  • 响应格式报错排查：若站点返回 invalid_parameter_value (param: response_format)，说明该模型不接受该字段，将「响应格式参数」保持为「不发送该参数」即可正常生图。

提示词替换规则

Banana/Grok 专属的替换词设置，独立于其他生图后端。格式：触发词=模式|替换内容

替换模式说明
  • 前置前 - 在提示词最前面插入内容
  • 前置后 - 在前置固定词后插入内容
  • 替换 - 直接替换触发词（留空则删除）
  • 替换分角色 - 分角色模式下替换
  • 后置前 - 在后置固定词前插入内容
  • 后置后 - 在后置固定词后插入内容
  • 最后置 - 在提示词最后面插入内容
