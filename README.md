# st-chatu8 智绘姬 · 角色DNA 融合版（3.1.9）

把两个插件合成了一个：

| 原扩展 | 版本 | 融合后的位置 |
|---|---|---|
| **st-chatu8（智绘姬）** — 文生图 / LLM 出 Tag / 酒馆陪伴 | 3.1.9 | `chatu8.js`（核心，逻辑原样保留） |
| **st-chatu8-dna（角色DNA记录器）** — 边聊边整理角色档案 | 2.9.33 | `dna.js`（内置，不再需要单独安装） |

装一次、启用一次，智绘姬设置面板左侧就会直接出现 **「档案库」** 页签。
角色DNA 依然复用智绘姬的 LLM 配置、正则配置和发送请求，行为和原来一样。

---

## 本版更新

**智绘姬 3.1.8 → 3.1.9**
- NovelAI 的 API Key 支持查询余额
- LLM 参数收纳，避免误触

**角色DNA 2.9.33**
- 档案分库方式三选一：全局共用一份 / 跟随角色卡 / 跟随角色卡存档（老的开关自动迁移）
- 角色条目「复制」改为「导出」，可单独导出一个角色的档案 JSON
- 小锁旁新增「设为全局」：全局角色在任何角色卡、任何存档都可见，并自动置顶
- 修跨角色卡误触发：进会话时聊天未加载完，不再把历史楼层当成新增而白跑一次记录

---

## 安装

1. **先删掉旧的**：把 `extensions` 里的 `st-chatu8-dna` 整个文件夹删掉（或移走），
   旧的 `st-chatu8` 也删掉。**不要新旧同时存在**，否则 DNA 会跑两遍。
2. 把本压缩包里的 `st-chatu8` 文件夹放进 `SillyTavern/data/<你的用户名>/extensions/`。
3. 重启酒馆（或刷新页面），在「扩展」里启用 **st-chatu8 智绘姬（角色DNA融合版）**。

## 注意

- 本包**已关闭在线更新**（点更新只会弹提示）。升级请整包替换，不要用酒馆的更新按钮，
  否则融合进来的 `dna.js` 会被官方原版覆盖掉。
- 三个档案库上下文预设、同人资料库数据都已随包内置，无需另外下载。
