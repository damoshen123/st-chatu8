# st-chatu8 智绘姬 · 角色DNA 融合版（3.1.8）

把两个插件合成了一个：

| 原扩展 | 版本 | 融合后的位置 |
|---|---|---|
| **st-chatu8（智绘姬）** — 文生图 / LLM 出 Tag / 酒馆陪伴 | 3.1.8 | `chatu8.js`（核心，逻辑原样保留） |
| **st-chatu8-dna（角色DNA记录器）** — 边聊边整理角色档案 | 2.9.31 | `dna.js`（内置，不再需要单独安装） |

装一次、启用一次，智绘姬设置面板左侧就会直接出现 **「档案库」** 页签。
角色DNA 依然复用智绘姬的 LLM 配置、正则配置和发送请求，行为和原来一样。

---

## 安装

1. **先删掉旧的**：把 `extensions` 里的 `st-chatu8-dna` 整个文件夹删掉（或移走），
   旧的 `st-chatu8` 也删掉。**不要新旧同时存在**，否则 DNA 会跑两遍。
2. 把本压缩包里的 `st-chatu8` 文件夹放进
   `SillyTavern\data\default-user\extensions\`
   （用别的用户就放对应用户目录）。
3. 刷新酒馆页面（`Ctrl+F5`）。
4. 打开智绘姬设置面板，左侧导航最下面就是 **档案库**。

> 你的设置不会丢：智绘姬的配置仍存在 `extension_settings["st-chatu8"]`，
> 角色DNA 的档案仍存在 `extension_settings["st-chatu8-dna"]`，键名和原版一致。

---

## 关于在线更新

融合版的「在线更新」已被改成一句提示：**本包不能在线更新**。
点它只会提醒你「在线更新会覆盖融合内容」。
升级请整包替换：删掉旧的 `st-chatu8` 文件夹，放进新的融合包，刷新页面。

## 3.1.8 相对 3.1.7 的变化（智绘姬本体）

- NovelAI V5 噪点表（`noise_schedule`）可单独设置，默认「不发送」
- NovelAI 模型切换后的参数面板显示逻辑整理（`updateNovelaiModelUIState`）
- 图生图 / 重绘流程同步适配 V5 噪点表

## 档案库（角色DNA 2.9.31）要点

- 档案字段第三栏是 **同人标签**：`作品tag, 角色tag` 的英文 danbooru 标签（原创写「无」）
- 楼层倒计时：设置「每 N 层记录一次」→ 显示 N+1，倒数到 1 时自动点一次「立即记录」，
  这一轮跑完再回到 N+1
- 三套内置上下文预设随包附送，改版后会自动重装一次
- 使用说明按钮在档案库顶部，打开在线文档
